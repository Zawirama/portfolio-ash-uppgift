Home site is here to give he user an overwiev of everything. The about me page is to tell people about me and my skills. The projects page showcases my projects.

I chose to use 1000px as my only break point since i think it is a good break between ipads and big ipads/small laptops. No other break points are nedded since the website works and looks good on all smaller screens.

Flexbox is used on the main navigation becouse the links only need to be adjusted in one direction and grid is used on the projects section becouse I wanted the projects to be abel to be side by side too not leve to much empty space in big screens. The elements within the projects use flex box since they just need to be in a collumn that's centerd.

one problem which i fixed was one where images could sometimes couse horizontal scroll if they were big enough i fixed that by limiting the size of the projects as well as using max width isnsted max height on small screens.

The second problem i fixed was one where on big screen there would be empty space next projects that hade no project to be next to which i fixed by making a big class made the project span 2 columns.
